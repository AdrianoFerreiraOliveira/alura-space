<h1>Alura Space</h1>

<p>Alura Space is a website that serves as a gallery of space images, featuring galaxies, planets, stars, and more. It was developed with React and SASS in an ALURA course.</p>

<h2>🚀 Project Overview</h2>

<p>Alura Space is a project that showcases various photos of galaxies, planets, stars, and others, with an option to filter images by theme. It simulates an API for the images and was built using React with reusable components styled with SASS. The project was proposed as part of an ALURA course.</p>

<h2>🔨 Project Features</h2>

![image](https://github.com/user-attachments/assets/bace5493-5ca3-4a63-a1fb-1c1a410d7dfb)


<ul>
  <li>Feature 1: Easily update new photos via a mock API.</li>
  <li>Feature 2: Filter photos by themes such as galaxies, nebulas, stars, and the moon using buttons.</li>
</ul>

<h2>✔️ Technologies Used</h2>
